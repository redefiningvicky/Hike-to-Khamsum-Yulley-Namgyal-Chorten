<h2 id="objective">🎯 Objective</h2>

<p>
  This project focuses on mapping the hike to Khamsum Yulley
  Namgyal Chorten in Punakha District, Bhutan. It tracks the
  entrance and exit trails, visualizes geographic data, and
  provides details such as photographs and hike difficulty.
</p>

<hr>

<h2 id="project-details">🛠️ Project Details</h2>

<p>
  <strong>Tools:</strong> ArcGIS Online, ArcGIS Dashboards,
  ArcGIS Field Maps
</p>
